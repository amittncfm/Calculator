# 🧮 Simple Calculator

A beautiful, fully functional calculator built with HTML, CSS, and JavaScript.

## 🎯 Features

✅ **Basic Operations**: Addition, subtraction, multiplication, division  
✅ **Decimal Support**: Handle decimal numbers  
✅ **Percentage**: Calculate percentages  
✅ **Toggle Negative**: Change sign with +/- button  
✅ **Clear Function**: Reset with C button  
✅ **Keyboard Support**: 
   - Number keys (0-9)
   - Operators (+, -, *, /)
   - Enter or = to calculate
   - Escape or C to clear
   - Backspace to delete last digit

✅ **Modern UI**: Beautiful gradient background, smooth animations, and responsive design

## 📂 Files Included

- `index.html` - Main HTML structure
- `style.css` - Beautiful styling with gradient background
- `script.js` - Calculator functionality with keyboard support

## 🚀 How to Use Locally

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start calculating!

## 💻 Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0-9 | Enter numbers |
| +, -, *, / | Operations |
| Enter or = | Calculate result |
| Escape or C | Clear display |
| Backspace | Delete last digit |
